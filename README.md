# J26-IT-304: Adaptive AI Tutor for Java Programming
This repository holds one component of the J26-IT-304 research project (SLIIT): an **adaptive AI tutor for Java**. A student chats with the tutor about a Java topic. When the student seems
confused, the tutor explains the idea again **using a different teaching strategy** (theory, then an example, then a simpler version, then an analogy) instead of repeating itself.
